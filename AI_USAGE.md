# AI Usage

I used AI during the assignment mainly when I got stuck with the analysis or
needed to check my calculations.

I used it to:

- understand parts of the existing fertility script
- come up with commands for checking the results
- check calculations from the benchmark outputs
- help organize the findings in the A2, A3 and A4 files

I ran the commands myself in PowerShell and used the outputs from my own
runs for the results in this repository.

I also used AI to help with some wording and formatting of the documentation.
